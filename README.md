# אמירות

**[https://amirot-gh.vercel.app](https://amirot-gh.vercel.app)**

הגרסה האחרונה שמוזגה, בלי Vercel: https://raw.githack.com/Anat1969/Amirot-GH/main/app/index.html
אם מופיע דף ביניים "One more step", לוחצים פעם אחת על "Open the page".

אטלס של 252 פתגמים וציטוטים מ-38 תרבויות ו-24 מחלוקות. כל תרבות אומרת משהו, ואת ההפך שלו.
האפליקציה מניחה את האמירות בצורת דף גמרא, ומחשבת מה דומה למה, מה סותר את מה, ומתי כל צד נכון.

## הרצה
```
npm install
npm run dev
```

## מבנה
- `src/data`: המאגר (אמירות, רעיונות ותרבויות), מקור הנתונים היחיד.
- `src/engine.ts`: קשרים, מרחקים, מגמות וחיפוש עברי. הכול דטרמיניסטי.
- `src/pages`: הבית, הדף, המראה, האטלס, המגמות והכתבה.
- `tests`: מאגר, קצה לקצה, התאמה למסך, חפיפה וגבולות שרטוט.

## החלטות
- **בלי שרת:** הכול רץ בדפדפן, והשמירה מקומית.
- **בלי מודל בזמן ריצה:** הקשרים מחושבים בקוד מתוך המאגר, ולכן כל ממצא ניתן לשחזור.
- **תאריך רק כשיש תיעוד:** פתגם עממי נשאר בלי שנה.
